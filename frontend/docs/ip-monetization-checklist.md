# IP Protection And Free-Access Monetization Checklist

## 1) IP Protection Steps

### Brand and naming
- [ ] Decide final commercial name usage (`Deadball Academy`, `Deadball Lab`) and enforce consistent branding.
- [ ] Perform basic trademark clearance search before filing.
- [ ] File trademark application for core brand word mark when budget allows.

### Copyright and licensing
- [ ] Add explicit copyright notice in footer and repository.
- [ ] Publish Terms of Use clarifying ownership of curriculum text, diagrams, and lesson structures.
- [ ] Publish content usage license for learners/instructors (what is allowed for classroom reuse).
- [ ] Document provenance for authored lesson content and future diagrams.

### Policy and legal hygiene
- [ ] Add/update Privacy Policy describing auth/profile/progress data handling.
- [ ] Add acceptable use language for account abuse and scraping boundaries.
- [ ] Define instructor contribution policy before any multi-author workflow is enabled.

## 2) Monetization While Keeping Content Free (No Paywall)

### Primary channels
- [ ] Sponsorship model for public-facing pages (transparent sponsor disclosures).
- [ ] Grants/foundation applications for open education and STEM learning.
- [ ] Donation support path (one-time + recurring) for learners who want to contribute.
- [ ] Institutional services model (implementation support, onboarding, custom curriculum maps), while core content remains free.

### Guardrails
- [ ] No lesson or core curriculum paywall.
- [ ] No locked assessments required for standard learner progression.
- [ ] Revenue products must be support/services, not content restriction.

## 3) Solo Dev vs Crowdfunding Decision Gate

### Continue solo if all are true
- [ ] Monthly infrastructure + tooling cost remains sustainable.
- [ ] Support load stays manageable without delayed bug/security response.
- [ ] Feature roadmap remains executable within part-time/solo capacity.

### Trigger funding if any are true
- [ ] Security/compliance work exceeds solo bandwidth.
- [ ] Instructor adoption demand requires onboarding/support beyond available time.
- [ ] Content production and QA cadence slips for multiple cycles.
- [ ] Infrastructure costs outpace sustainable personal funding.

## 4) Near-Term Execution Order
1. Finalize Terms + Privacy + Copyright notices.
2. Launch donation/support CTA and sponsorship policy.
3. Build institutional supplemental-curriculum services offer sheet.
4. Reassess quarterly with concrete metrics:
   - active learners
   - active instructors
   - support requests/week
   - monthly operating cost
   - monthly voluntary/support revenue
